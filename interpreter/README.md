# Interpreter

This repository contains an implementation of an interpreter for a simple programming language called **Plox**, built by following the book **Crafting Interpreters**. The project was created primarily for learning purposes.

The implementation includes the core components of an interpreter:

- **Lexer** : performs lexical analysis  
- **Parser** : builds the Abstract Syntax Tree (AST)  
- **Resolver** : handles semantic analysis  

The runtime environment is implemented in **Python**.
